# Instruksi untuk Claude Code (jika project ini dilanjutkan/dipindah ke Claude Code)

Catatan: project ini saat ini dibangun dengan MiMoCode (lihat ADR-015 di DECISIONS.md).
File ini disiapkan untuk portabilitas jika di masa depan berpindah ke Claude Code.

Sebelum membuat perubahan apa pun, baca:
1. `MEMORY.md` — status, sprint aktif, instruksi agent
2. `DECISIONS.md` — seluruh keputusan arsitektur (ADR)
3. `docs/00-project-overview.md` — problem, solution, differentiator, scope
4. `sprints/SPRINT-[N].md` — sprint aktif

Jangan menyimpang dari `DECISIONS.md` tanpa mencatat ADR baru.
